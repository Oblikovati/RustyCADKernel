# Martensite 0.2.2

This package update gives Oblikovati the integrated visualization work since
0.2.1: live view, subview and light references; ColoredShape appearance and
lifecycle behavior; textured-shape source callbacks; and safe, scoped texture
retirement callbacks with native ownership ordering.

CView bounds and zoom queries now retain the selected borrowed camera field
across window callbacks. Removing an exhausted clipping iterator is a no-op,
matching the native behavior. Rust tests replay committed native oracle assets;
consumers do not need an OCCT build to run those tests.

Parallel Linux rendering checks use a verified validation-layer dependency.
Inventory lookup scans are reduced while preserving full report semantics.
The DWG backend decision selects acadrust behind a Martensite-owned adapter;
DWG integration follows visualization and Vulkan work.

The port remains incomplete. Live clipping contracts, the full Frame/controller
path, ColoredShape presentation prerequisites and further Vulkan compatibility
work are under development. This release does not claim complete legacy renderer
parity or complete OCCT API coverage.

Publication requires the extracted package archives to pass all-target tests and
doctests in both default and all-feature configurations. All 31 package versions
and their internal dependency requirements are 0.2.2.
