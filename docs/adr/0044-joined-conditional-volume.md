# Joined conditional volume, version 1

Kernel #10 needs volume with certified error. The existing signed sweep integral
is retained unchanged, including its negative values, representative convention,
requested limits and replay fixtures. This additive private interpretation uses
that result and the existing exact orientation certificate for the identical
immutable join. It does not introduce an integration algorithm or valid-body flag.

## Exact interpretation

For the currently admitted single polynomial Jordan boundary, let `q` be its
increasing-native-parameter winding, `r` its explicit traversal factor, and `J`
the constant support/sweep Jacobian. Existing orientation derives `q` from the
fresh faced winding and retains the exact nonzero sign of `J`. Existing measures
integrate that same copied boundary with traversal `r` and that same support and
extrusion. Consequently the signed sweep integral has sign `s = q*r*sign(J)`.
The bounded region's physical volume is `s` times that integral. No rounded
scalar, normal, coordinate ordering or tessellation determines this sign.

Both child proofs must match the complete join bytes. Every sign factor is
checked as exactly `-1` or `1`, the selected winding as `1`, and the retained
faced-winding relation as consistent. Foreign bindings and inconsistent inputs
return typed incompleteness; cancellation returns no partial volume.

Given a certified signed enclosure `[lo, hi]`, representative `p` and error
bound `e`, the interpretation returns:

- For `s = 1`: enclosure `[lo, hi]`, representative `p`, error `e`.
- For `s = -1`: enclosure `[-hi, -lo]`, representative `-p`, error `e`.

Binary64 negation is exact, and multiplication by either sign is an isometry:
`|s*p - s*I| = |p-I| <= e`. The negative branch deliberately uses the **upper**
positive enclosure endpoint as its representative. Claiming lower-endpoint
semantics after negation would require a different certified error. The new
type therefore does not reuse or relabel `CertifiedPolynomialMeasure`.

Nonzero exact volume may have a zero outward lower bound under underflow. That
does not invalidate the exact sign proof. All original limits, effective
settings, error bits and the original signed report remain available; there is
no clamp, revised tolerance, reduced error or intermediate reintegration.

## Ownership, replay and scope

The result owns immutable scalar operands and complete portable join,
orientation and measurement receipts. Its versioned replay includes all sign
factors, transported bounds, representative, error and complete child receipts.
Earlier signed APIs and complete publication V1 bytes remain selectable and
unchanged. The future owned operation envelope can add this explicit quantity
after its integration gate; the existing private assembler is not rewritten.

The interpretation is conditional on the existing joined domain. It supplies
neither complete history nor final source rebind, general-profile support,
application persistence or operation publication. The complete operation still
owns those gates. Arithmetic extreme-placement fixtures test sign transport;
they do not assert that the live construction pipeline admits those placements.

Independent expectations include the cubic's exact `24/5` volume for either
extrusion direction, stored-pole versus traversal reversal, exact sign-factor
products, non-unit support scaling and a subnormal `3*min_subnormal/20` case.
Refusal, every callback cutoff, owned-input drop, repeat-process and concurrent
read checks preserve the existing scalar and replay corpora. Execution evidence
is recorded separately; this decision alone grants no acceptance or release.

Kernel #10 retains the existing application R3 deletion task and one-milestone
migration limit. No production path is superseded by this additional quantity;
the signed integral remains useful and is not scheduled for deletion.
