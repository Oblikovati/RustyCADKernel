# ADR0045: private owned polynomial prism request

Status: admission/construction/orchestration checkpoint; semantic correspondence
and complete publication integration remain pending. Behavior: owned request V1.
Kernel #10 bounded prerequisite, not public API or release completion.

## Small caller Interface

The caller supplies an operation ID, a collection of polynomial sources, declared
plane, bounded-region-containing seed, extrusion and explicit policy bundle.
Each source owns world-space poles, source/revision/closure vertex/native start
and end use IDs and an independent traversal flag. There are no Shape/Handle
inputs and no caller-authored intermediate stage IDs. The operation keeps exact
input values; a revision number alone never establishes reusable evidence.

The policy bundle preserves separate census, original/construction conformance,
contact parameter/world, classification, prism spatial/parameter, and complete
publication/validation/history/measurement settings. The preparation stage does
not claim that deferred publication settings have been applied. Existing child
operations perform their own policy validation without silent redistribution.

Empty input is a typed decline. Multiple sources and unsupported request versions
are explicit incomplete domain refusals. Open boundaries are incomplete in this
closed-boundary domain. Invalid scalar/name inputs fail admission; numerical and
mapped operation failures retain their actual typed child causes. Outside and
boundary seed outcomes stay explicit private refusals, not completed empty solids.

## Constructor authority and shared pipeline

ADR0042 creates the semantic dictionary before construction. Its fixed Original
Boundary token is the operation-local RegionSourceId; the full caller source ID
remains in the dictionary and owned request. No source enumeration supplies names.

The constructor reuses GeomBezierCurve, BRepBuilderAPIMakeVertex and
BRepBuilderAPIMakeEdge::from_curve_vertices_params with the same explicitly held
closure vertex at native parameters 0 and 1. It retains the actual forward edge,
native endpoint uses and the independently oriented source edge. Caller start/end
IDs are never swapped when traversal reverses. The existing BRepTool parameter
query on a reversed closed edge swaps its endpoint interpretation: tests pin
native forward-edge 0/1 separately from oriented-source 1/0.

The production orchestration calls existing source capture/conformance census,
owned partition observation, actual candidate copy observation, partition binding,
paired contact transport and retain_source_bound_prism. It does not call any
cfg(test) fixture, add another classifier or change existing entry points.

A prepared stack retains only private diagnostics and the existing incomplete
PrismReceipt. It is not a successful operation result. Partial failures retain
request/source and actual available stage receipts; errors consumed by a child
retain that child's original payload. These private failures may contain mutable
local topology and are deliberately outside the future owned refusal contract.

## Context and ownership

The injected progress trait is Send and has ordered, typed phase/ordinal events.
The first callback cancellation/error is terminal; a callback error remains an
outer Failed outcome while preserving any child cancellation diagnostic. Native
constructor/copy/interference calls remain synchronous; cancellation is observed
at their existing checkpoints and added stage boundaries, not inside those calls.

Inputs are owned scalar buffers. Constructor-created geometry is operation-local;
retained native and oriented handles intentionally alias that private definition.
The context and actual prepared/failed state have compile-time Send assertions.
They are not published immutable bodies. Full threaded replay/TSan and immutable
publication proof remain whole-operation gates, not consequences of Clone or Send.

## Shared portable body-name map seam

The first resolver prefix adds only an immutable read Interface and strict table
checks. Its production issuer remains unavailable until actual constructor,
copy/history and full-context correspondence is implemented. A test-only explicit
row constructor can check a supplied accepted publication's key universe; token
validity and publication bytes alone are not semantic correspondence evidence.
Symbolic fixtures are explicitly unbound to a real publication. The unchanged
legacy publication fixture refuses, rather than gaining dictionary meaning through
an order-based translation.

`SemanticMemberKey` expands the full frozen definition key into the caller
operation/boundary namespace, dictionary source-member slot, sweep role and kind.
`SemanticUseKey` retains every member/use step in its complete ancestry. A generic
FaceUse or LoopUse slot alone never identifies an occurrence. Output roles such as
FirstCap are separate checked metadata. V1 reserves no First/Last/SideWire member
tokens: those three definitions retain their qualified source/sweep/kind keys;
LoopUse is never repurposed as a member identity. The 97 V1 reservations and prior
name/child serializers remain unchanged. Actual applicability and complete stage
coverage are later resolver obligations, not inferred from dictionary reservation.

The map checks exact unique domains in both directions, canonical expansion,
source/use role applicability, ancestor prefixes and reverse collisions. Its own
versioned replay contains the full unchanged name envelope and publication bytes,
plus every sorted member and directed mapping row. These owned scalar types have
no mutable geometry, address, cache, lock or allocator callback. The body-read
projection consumes this one map and checks all referenced member/use keys; it
must not allocate or decode a second naming scheme. Complete owned request bits,
revision labels and policies belong to the separate request envelope, not the
existing names-only envelope.

## Actual correspondence and sealed invocation checkpoint

The private resolver now follows constructor-held native endpoint handles through
actual initial-copy queries, unchanged partition queries, candidate-copy queries,
the freshly certified selected/complementary faces, and selected-copy ancestry.
Each stage requires exact unique complete context coverage. Fresh bounded source
capture includes child paths. Returned indices only retrieve uniquely matched
operands; they never author names. The existing complete publication operation
still proves all native history, parents, geometry and ordered body gates.

Output use names use the actual fresh three-chart/six-trim coverage. Both vertices
of the source-start seam occurrence retain the caller's native-start anchor;
both vertices of the source-end seam occurrence retain native-end. Actual
First/Last vertex keys and complete parent ancestry distinguish sweep ends.
The seam's own sweep parameter must not reinterpret source parameter 0/1.
Cap/side rim endpoint uses retain their source native parameters independently
of stored-pole and traversal reversals.

The private publication field `selected_region` requires the authored name of
its **copied sweep base**, not the earlier selected candidate's stage name.
The initial full-entry attempt retained the exact join refusal for that mismatch.
Using SweepBase/BoundedRegion reaches the unchanged complete publication but
exposed the symbolic V1 map's assumed Selected-stage root as insufficient for
this actual operation. Dictionary V2 therefore additionally admits Generated
Solid/Shell definitions sourced by SweepBase/BoundedRegion. V1 admission and
replays remain unchanged; other stages, source roles and sweep roles do not gain
this admission. No join predicate is relaxed and no reserved token is reassigned.

`ResolvedPrismInvocation` owns the actual source slice and resolved binding tables
while borrowing the prepared operation. Only its real publication call can create
`ResolvedPrismPublication` or `InvokedPrismPublicationFailure`. The latter captures
owned exact request/plan values, retains the original outer class and nested
failure, and borrows bindings with the invocation lifetime. There is no constructor
pairing an arbitrary caller header with a later failure. Equal geometry can have
identical legacy publication bytes/internal tokens in two caller namespaces;
that is why token equality alone cannot establish invocation origin.

The production name-map issuer accepts only the sealed successful publication.
It expands the actual accepted 13-definition/26-use universe, checks full unique
coverage and ancestry, and retains the complete publication bytes. A reusable
test fixture invokes this production path with V2 names authored before geometry;
it never calls a fixture identity allocator. The map's schema remains V1 and its
contained dictionary is V2. A name map binds naming and child-publication bytes;
full request revision/policy provenance remains separately owned by the sealed
invocation and will enter the complete owned outcome envelope.

This checkpoint remains private. The one-call owned operation still needs its
monotonic preparation/resolution/publication/body progress context, complete
request/diagnostic/body envelope, full frozen tests and concurrency evidence.
Reservation applicability must be reported explicitly: unmaterialized region-role
reservations are not observed entities. No public general-profile admission,
application edit/history completion, or Kernel #10 release claim follows.

## Reservation applicability

The additive `PrismReservationCoverage` inspection accepts only the sealed actual
publication and its exact issued map. It reads the accepted complete history's
seven-stage context keys, request operation/contact keys, output member
associations and final directed-use steps. It performs no live capture or
identity allocation. Each of the 101 V2 reservations receives either an actual
named-field application count or a typed inapplicability reason. Repeated physical
members in distinct contexts contribute repeated named fields; these counts are
not definition cardinalities.

For the admitted single unsplit boundary, 73 reservations apply. The 28 remaining
slots are the eight region roles at each pre-generation partition/candidate-copy
stage, four complement roles at selected and sweep-base stages, and four bounded
roles at the complement stage. Missing applicable slots and observed applications
of inapplicable slots refuse explicitly. The report's own V1 replay binds the full
unchanged map bytes plus every ordered applicability row. Legacy map and naming
replays are untouched. This report explains reservations; it adds no geometric
completion authority and does not replace the exact request/revision envelope.
