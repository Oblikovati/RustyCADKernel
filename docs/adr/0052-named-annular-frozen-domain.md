# ADR 0052: Named annular frozen domains and topology

- Status: interface checkpoint; no annular body acceptance.
- Baseline: main `aa0aa06ed`, development binding dependency `f7c1036c7`.
- Scope: private Kernel #10 two-polynomial-boundary prism prerequisite.
- Behavior: additive annular V2 join/domain policy; existing V1 capture,
  single-Jordan topology and all historical bytes remain selectable unchanged.

## Interface and ownership

`join_annular_frozen_domain` receives the retained two-loop request, actual prism
receipt, explicit authored publication bindings, and the existing owned annular
embedding evidence. It reuses the frozen capture pipeline with ordered traversal.
It returns either a typed refusal or an immutable owned join retaining exact proof
operands, projection, full named face/wire/trim/source correspondence and replay.

The last external callback precedes callback-free current embedding rebinding and
fresh frozen projection/name comparison. An operation-local lookup identity is
never a published key. The same source geometry and all context ancestry must
match; revision labels, matching coordinates or parent sets cannot substitute.

`certify_annular_frozen_topology` takes that joined proof and uses the existing
finite incidence checker through `FaceDomainPolicy`. Only the owning join can
construct the domain policy. No caller-provided Euler weight or loop-count guess
can supply authority. The topology certificate binds the complete joined bytes.
Neither result grants full ordered validation, complete history or body validity.

## Existing capabilities and constraints

Reuse `PrismPublicationBindings`, source-plus-sweep-role definition keys, full
`FrozenUseKey` ancestry, exact chart capture, fresh graph audit, ordered wire
traversal, endpoint checks and existing containment/incidence/link/connectivity
checks. The frozen container already supports plural faces and source names.

An exact bijection must cover four actual faces, six directed wires and twelve
trim uses. Certified cap domains are annuli with explicit outer/inner wire roles;
the two side parameter charts are seam-cut disks. Their contributions are 0,0,1,1,
so the actual product fixture has V-E+sum(domain Euler)=4-6+2=0. This arithmetic is
conditional on the exact bound domains, and does not establish them by itself.

Preserve every existing freeze admission rule. If a present legacy region failure
blocks actual capture, retain the real refusal and seek a reviewed versioned
owned-certificate admission; never erase it or manufacture successful geometry.
The public single-boundary semantic dictionary is not extended implicitly: this
slice receives explicit plural member/use names authored before lookup.

## Verification and migration

Pin V1 and two-loop replay bytes before changes. Use the actual existing annular
builder/copy/sweep with independently specified loop roles and combinatorial
expectations. Cover missing/duplicate/swapped/foreign full contexts, same-role cap
rims, native seams, stale callbacks, cancellation, isolated inputs and owned
Send/Sync/process/thread evidence. No live OCCT oracle, tessellated substitute or
new modelling engine is introduced. Existing ordinary-host sanitizer startup
limitations remain explicit; no probe bypass or host change is authorized.

Within Kernel #10, compose this proof with plural orientation, geometry,
self-intersection, tolerance, complete history and certified measurements in the
existing ordered publication pipeline. Delete temporary fixture adapters after
one complete named annular operation passes that corpus. Retire overlapping V1
private glue only through a recorded migration preserving historical replay;
this private additive slice does not change the released workspace version.
