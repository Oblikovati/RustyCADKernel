# Source-bound plural trimmed-prism embedding

Status: implementation in progress; no plural-body publication authority.

## Decision and scope

Reuse the existing affine-product theorem and actual chart capture for the
priority-0 sketch with a hole. Behavior V1 remains selectable and its fixtures
remain unchanged. The first V2 admission is a certified nested pair of polynomial
Jordan loops, using the existing arrangement and sweep builders. It is a bounded
step toward general profiles, not completion of Kernel #10.

The region certificate must prove both closure-only self domains, the complete
empty cross domain, strict nesting, material selection, and every actual candidate
and directed member. The swept binding must connect that exact certificate and
request to the actual selected/copy domains, all four face contexts, all trims,
and the exact nonzero signed affine Jacobian. Full source/copy/chart operands
are recaptured without callbacks after the final callback before issuance.

## Shared implementation and behavior preservation

First extract the existing seam/rim conclusion construction into a private
module, preserving check messages, ordering, endpoints, domains and parent
multiplicity. Both V1 and V2 use these primitives. A primitive checks only the
supplied trim correspondence; it confers no independent geometric authority.
Keep V1 role-only selection and its three-domain/six-row admission unchanged.
Do not silently reinterpret its Jordan-cap domain as an annular domain.

The V2 domain description names both cap boundary loops with their exact source
roles and winding evidence; each side names its own generating source and native
endpoint correspondence. Domain and pair lookup use complete bound identities,
not the shared Generated role, output order or topology-address rank. Native
operation-local contexts may be compared for binding; they are never persistent
identity or the serialized source of a caller name.

## Mathematical obligations

For F(u,v,s)=A(u,v)+sE, the exact nonzero determinant makes F injective. Applied to
the same certified closed annular material domain (including both boundary
curves) and s in [0,1], this yields ten unordered face
pairs including the diagonal:

| Pair class | Count | Required conclusion |
| --- | ---: | --- |
| Cap self | 2 | Injective certified planar annulus |
| Side self | 2 | Injective modulo its authored closure seam |
| Distinct caps | 1 | Disjoint |
| Cap and side | 4 | Exactly the matching authored rim |
| Distinct sides | 1 | Disjoint from the complete cross-boundary proof |

The seam quotient identifies only native parameters 0 and 1 at equal normalized
sweep. It does not assert C1 closure or smoothness at a corner.

The ten-pair census is not a geometric proof by itself. Each row needs the same
full region/source/chart binding. Both cap rims have the same trim role; selection
must match their actual generating source and output incidence uniquely. Shared
physical incidence is checked once and retained with each directed use. Missing,
duplicate, foreign or altered rows, parents, intervals or binding bytes refuse.

Per-boundary regularity budgets and aggregate work limits are explicit. Exhaustion
is incomplete. New code does not multiply a prior single-curve budget silently.
No tessellation, coordinate-proximity inference, retry ladder or faceted fallback
is admitted. Embedding does not replace ordered topology, geometric consistency,
tolerance, complete history, measures, or immutable publication checks.

## Verification and migration

Before the structural change, run the owned V1 embedding corpus and preserve its
existing independent fixture. After extraction, require unchanged complete join,
ordered validation and publication replay bytes as well as embedding behavior.
V2 tests must exercise actual nested-curve construction, source and row reorder,
all missing/duplicate/foreign pairs, stale binding, mutation, cancellation and
budget boundaries. Compare independent processes and thread counts. Sanitizer
startup failure remains incomplete and never a waiver.

Keep the test-only finite topology fixture explicitly separate from production
geometric domain authority. Once the complete same-operation V2 gate succeeds,
reuse it for the annular publication path. Remove temporary fixture adapters and
superseded production paths within this milestone; retaining explicit V1 replay
behavior is intentional until a recorded migration. Any externally breaking
change requires the corresponding version bump and migration notes.
