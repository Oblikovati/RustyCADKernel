# Paired contact construction transport

This private ADR0014 prerequisite joins `enumerate_source_bound_census` with
`bind_partition_outputs` through `transport_partition_contacts`. It retains both
owned inputs, their typed failures, the actual observations, requested limits,
work counts, and the remaining operation obligations. It returns no accepted
candidate or healthy body. Issue #10 kernel acceptance and consuming application
acceptance remain separate. Retained OCCT observations document provenance and
historical behavior; they are not an independent correctness oracle.

A report-local identity consists of the retained paired report and its original
candidate-root index. Reversed and repeated source occurrences retain their
actual parameter-axis mapping and complete original-member parents. This is not
a persistent name or a canonical identity across reports. A vertex incident to

## Evidence and construction limits

The bridge consumes the existing paired provider; it has no additional root
solver. The provider retains the exact rational `RatioInterval` already computed
for the paired parameter before its existing outward binary64 conversion. The
original t bracket, outward values, arithmetic, constants, cancellation polls and
failure ordering remain unchanged by that retention step. The borrowed view does
not manufacture a dyadic paired parameter or reinterpret a rounded value as exact.

Original-curve to captured-basis correspondence is independently checked with the
existing transported metric engine at a zero threshold over the declared domain.
A nonzero conformance allowance, a rounded upper bound, or admission metadata
cannot substitute for that identity evidence. General planes and parameter maps
remain in scope; an unavailable exact correspondence remains incomplete. The
corpus includes actual translated source geometry and support away from z=0.

Native t and u values are transported by the existing exact affine parameter
maps. The bridge reports separate requested native-parameter limits and exact
conservative error enclosures. A straddling threshold is inconclusive. Native
scalars are never snapped to root brackets, and brackets are never widened to
include approximate native cuts.

World construction uses actual DS, copied-image and directed-generated vertex
points captured while those real shapes are available. The existing residual
engine compares the actual constant point to the original curve on the exact t
bracket. A `Within` result is a sufficient envelope for that whole bracket.
`Exceeds` on a nonsingleton bracket does not establish that the algebraic contact
itself exceeds the limit; it means this construction envelope did not prove the
requested bound. Requested source, parameter and world bounds remain distinct.

A local bounded construction requires the complete source-bound contact count,
a unique actual shared DS vertex/parameter tuple, simple-root evidence, exact
source correspondence, parameter and world bounds, all incident-source checks,
and complete kinded native/copy history. The counts and exact root evidence are
required in addition to the construction bounds. Large limits cannot choose
between two roots or replace topology with proximity. This local receipt concerns
the retained observations, not subsequently mutable geometry or complete search.

The current source/partition inspection uses the census's original descriptors.
Checking only the partition's own originals would permit a source edit between
the two captures when topology identity and contact coordinates happen to survive.
The regression changes a cubic's two inner Y poles by opposite dyadic offsets,
preserving both endpoints and its exact midpoint contact. An old census is refused;
recapturing the census permits the same local construction checks again. Original
partition outcomes and their typed causes remain retained independently.

## Ownership, reuse and remaining gates

The zero-threshold source cache is operation-local and keys the actual physical
source group plus owned original/copy/pcurve/support/basis/trim inputs. Only
completed proofs enter it. Hits preserve occurrence attribution and historical
proof cost while charging zero new work. Failed/cancelled attempts retain actual
completed work and do not enter the cache. Original paired-census work remains
separate from this consumer's work ledger.

The retained paired enclosure adds 128 inline bytes on the measured target and
keeps four already-computed BigInt owners alive. This is not a measurement of
four additional allocations: heap capacities and comparative performance remain
unmeasured. Cache keys own scalar copies and local lookup costs; no performance
or memory improvement is claimed.

Rust controls cover mutation of original and copied census geometry, retained
results across later failure/cancellation/retry/source mutation, and bidirectional
copied polygon storage. The checked shared-copy corpus supplies the independent
full pcurve/mesh/cache isolation proof. These are scoped observations and tests,
not a claim that `Clone`, `Arc`, a shape reference or every reachable output is
immutable.

This private diagnostic transaction retains thread-confined compatibility shapes;
it is not a published immutable `Send + Sync` operation result. Publication and
operation concurrency acceptance remain open under the current kernel policy.

The whole transaction stays `Incomplete`. Original-source gaps, unsupported
correspondence, cross-report/triple-incidence equality, exhaustive partition and
candidate search, complete deletion/history coverage, ordered topology/geometry/
self-intersection/tolerance validation and prism/body certificates remain
independent obligations. No flags for those gates are discharged here. The
one-axis diagnostic path retains the deletion task and one-milestone limit in
[the paired census contract](sketch-region-paired-census.md).
