# Martensite integrated main Vulkan validation

Frozen main `71131d6607ca3d3b408fbacb797a36fde8a15acb` was checked on lavapipe and the native AMD host. Functional and optimized timing command exits are zero; both profiles pass offscreen acceptance and 26 selected Rust tests, including committed oracle-buffer replay. Captures cover54 Shadow cases, 19 text-culling cases, 4 named lights and 4 ViewCube default/lit variations per device. Strict failures are retained with unchanged gates; this is not full cross-device parity.

Each device ran63 optimized workloads (37 historical, 5 Shadow/named-light, 19 culling, 2 ViewCube), 20 warmups and 100 samples per workload. Lavapipe passes ten accepted historical budgets; AMD retains an exact device/driver identity mismatch. No baseline was accepted. Large source/sample/process manifests and logs are deterministically gzip-compressed. `receipt.json` is the review summary; full source/binary/workload/device fingerprints and raw samples are in the functional/performance receipts. Source and HEAD stayed unchanged throughout. Compiled native oracle executables were deleted after capture; their hashes remain in receipts and their build commands/source hashes are recorded.

Raw native/Rust `.rgba`/`.depth` buffers and PNG/diff captures are committed evidence suitable for comparison without OCCT. `capture-sha256.json.gz` pins them. Saved compressed harness scripts describe exact local invocations; they assume the checkout's existing target cache and pinned native OCCT build. Native dependencies are used only to generate oracle evidence, not by the Rust runtime.
