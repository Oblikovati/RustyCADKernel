# Owned partition observations

Martensite retains opt-in BOPDS source/pave/image observations before the local
mapped PaveFiller retires. The ordinary arrangement path passes no observer and
performs no extra DS access, progress callback, or receipt retention. The original
arrangement completion and typed operation failure remain authoritative.

The receipt records actual DS source indices, original occurrence parent sets,
source parameter ranges, own and common-block representative indices/ranges and
vertex indices, and the actual bound/unbound Builder image list with occurrence
identities. Representative parameters are not the original source's parameters.
Pointers are operation-local identity observations, never persistent identifiers
or retained topology handles. Locations retain the existing occurrence-key
semantics; no new geometry isolation theorem is claimed.

The native oracle pins OCCT 3d097a0328e71b826377d4814ab05ec3c3d23871 and runs
against `target/occt-all-full`. Its five real modes cover crossing splits,
unsplit edges, coincident distinct topology, opposite orientations, and relocated
occurrences. Both executions agree byte for byte. SDK/backing headers, libraries,
compiler, source and executable attribution are retained under `native/`; Rust
replays the attributed fixture without OCCT. Initial wrong-link-directory and
unsigned unbound-image sentinel diagnostics remain separately retained. The
sentinel correction changed only the oracle's output formatting.

The stage is observational, not a canonical parameter partition certificate.
Native Done, interval adjacency and image membership do not certify complete
contact roots, source correspondence, exhaustive pruning/search, candidate cycles,
self-intersection, or tolerance consistency. Missing context/source/image or
failed access remains typed incomplete; unbound and bound-empty lists differ.
Whole ordered region validation remains incomplete where those certificates are
missing. No compatibility API, numerical algorithm, limit, or successful region
contract is changed. No benchmark or baseline acceptance is claimed.
