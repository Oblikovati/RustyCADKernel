# Martensite v0.2.7

This release delivers the implemented Martensite kernel pieces for Oblikovati
integration. It preserves the existing `rustycad-*` package identifiers and
includes all 31 workspace packages. It does not publish packages to crates.io.

- Native GUI composition on the existing `Graphic3dRenderView`, with owned
  packets, clipping, alpha composition, font lifetime and resize validation.
  Functional captures and performance evidence cover lavapipe and the native
  AMD host.
- Accepted spline and exact predicate prerequisites, including a scalar triple
  product sign that handles binary64 cancellation, underflow and overflow.
- Public captured planar winding and whole-trim residual evidence. Internal
  construction ancestry and source-conformance checks reject changed captured
  geometry; these TKBO prerequisites are not downstream-callable APIs.
- Source-bound Bézier pair and self-contact certificates preserve exact root,
  sign, parameter and world-error evidence for supported product domains.
  Unsupported fibres and overlaps retain typed incomplete results.
- Internal selected-prism diagnostics retain copied geometry, contextual native
  history, cancellation causes and incomplete validation coverage. They remain
  private prerequisites for the region-to-solid operation.

The general sketch-region-to-solid certificate remains incomplete. Diagnostic
geometry is not a successful certified body. Unfinished partition and controller
work remains outside this release. OCCT is used only as a local porting oracle;
the packaged Rust regression tests run independently of OCCT.

Linux is the validated platform for this release; Windows and macOS checks are
deferred. The inventory remains below the full defined API scope. Application
acceptance requires Oblikovati's integration tests against the immutable release
revision.

The v0.2.6 attempt was not published: the hosted formatter caught two test
files reached through `include!` that `cargo fmt` did not visit. This patch
formats those files without changing their assertions or production code.
