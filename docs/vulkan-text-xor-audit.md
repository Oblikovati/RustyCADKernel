# Martensite native text Blend/XOR audit

OCCT's `Aspect_TODT_BLEND` uses a **bitwise color logic operation**, rather than an alpha blend approximation. At pinned `OpenGl_Text.cxx` lines 805–811, desktop OpenGL enables `GL_COLOR_LOGIC_OP` and selects `GL_XOR`; the ordinary foreground glyph pass follows. The existing font fragment shader still discards when color alpha times glyph coverage is at most 0.285. Text rendering resets the logic operation afterward. The OpenGLES path does not enable this desktop logic operation.

The local native probe observes `logic_enable = 1`, `logic_op = 5382` (`GL_XOR`) and `GL_BLEND = 1` during the real glyph draw. White glyphs over blue produce 102 solid yellow pixels. Changing foreground alpha to 0.4 yields 56 yellow pixels because of the font cutoff, rather than translucent yellow blending. Actual color/depth buffers, trace rows and PNGs are retained in `porting/runtime-evidence/decal-text-2026-10-12/native-blend-*`. Native `buffersOpaqueAlpha` keeps alpha writes disabled; the current Martensite attachment write mask already preserves that behavior.

Both host and lavapipe report Vulkan `logicOp = true`. The current device creation in `backend/runtime.rs` enables depth clamp, large points and wide lines, and does not enable logicOp. Current `backend/pipeline_state.rs` has no XOR logic-op pipeline. The color attachment is `R8G8B8A8_SRGB`; implementation must prove actual native fixed-point/sRGB encoding and color masks, including colored glyphs and destinations, rather than substitute a blend equation.

A bounded implementation would explicitly query and enable the optional core logicOp feature, report an unsupported capability before submission when it is unavailable, and provide a glyph pipeline with XOR logic state. It would preserve the native alpha discard, depth/offset/culling, ordered glyph placement, live colors and alpha write mask. Static pipeline logic state avoids requiring an extension beyond Vulkan 1.3. Native fixtures should cover repeated XOR, opaque and translucent glyph colors, destination patterns, alpha modes, annotations, planes, culling, layer writes and subsequent ordinary drawing to prove no state leakage.

This is suitable for a fresh checked branch after the standard 2D texture work integrates: both need device-feature and pipeline-state changes, which the texture agent currently owns. No Blend implementation, approximate blend substitute or API ledger credit was added in the Decal slice. Existing typed rejection and its Rust regression remain in place.
