# Martensite v0.2.8

This release adds the first generic, public modelling seam for Oblikovati's
"first cube" desktop slice. It keeps the existing `rustycad-*` package
identifiers and all workspace packages. It does not publish to crates.io.

## Public planar regions, extrusion and operation results

`rustycad_kernel::modeling` (from `rustycad_tkbo::profile_extrusion`, ADR 0068):

- `build_planar_regions(profile, resolution) -> PlanarRegionResult` turns a
  solved sketch profile (lines, circular arcs, circles) into validated planar
  faces with holes and a complete source-curve to generated-edge map. Curves
  join only through shared caller vertex ids; a rectangle uses the same path as
  any other profile. Regions are certified by the general loop proof (ADR 0066).
- `extrude(region, direction, options) -> Result<OperationResult, OperationDecline>`
  is a general extrusion that never changes its input region.
- `OperationResult` is an immutable owned body with sorted generated/modified/
  deleted history, ordered validation, findings, volume and achieved tolerance.
- `Resolution` separates weld, sew, angular and display tolerances and a
  report-or-refuse tolerance cap.

Ellipses and splines, touching loops and shared-edge regions are declined by
name. Arc-bounded region areas are closed-form with an unproven arc rounding
estimate; line-only areas are certified bounds.

## Public topology, tessellation and picking

- `BodyTopology` gives deterministic face, edge and vertex indices (ADR 0076).
- `tessellate(body, &DisplayOptions) -> PresentationMesh` meshes a copy of any
  body, keyed by stable face index, deterministic to the byte (ADR 0077).
- `ray_pick(body, &PickRay)` intersects exact surfaces and orders hits by
  distance, then face index (ADR 0078). Free-form faces are marked
  `SampledCandidates`.

## Certified sketch incidences

Trim and extension incidences are certified for line sources (ADR 0060) and for
circle, arc, ellipse and spline sources and angle-bounded arcs (ADR 0067).

## Porting progress

PrsDim dimensions and relations (TKV3d), the TKBool remainder and the
`ChFi3d_Builder` base fillet builder, TKernel/TKBO/TKXSBase/TKPrim/TKHelix
remainders. Linux cargo targets now run under the checksum-pinned Vulkan
validation layer 1.4.313.

## Earlier unreleased entries

### Private prism publication diagnostic retention V2

ADR0048 adds an explicit private publication V2 entry that retains each actual
downstream callback failure's phase, class and cause. The V1 entry and its legacy
admission/refusal/replay behavior remain selectable. V2 uses the same geometry,
validation, history, measurement and final-rebind pipeline; successful child
proof bytes remain unchanged, with the requested publication version recorded.

RustyCADKernel#10's operation-contract owner owns consumer migration and deletion
of the lossy V1 producer after the complete-operation retained-header corpus gate,
within ADR0014's existing application R3 limit. Old discarded headers are never
inferred retroactively. Caller-qualified immutable failure publication remains
pending the sealed invocation adapter and explicit unsupported-payload coverage.
No workspace version, public body domain or application acceptance changes.

### Private ordered joined prism validation

ADR0039 adds explicit validation behavior v1 for the admitted single-Jordan
polynomial prism. One immutable joined proof is checked in topology, geometry,
self-intersection and tolerance order; exact conformance is computed once and
reused by the explicit stored-tolerance cap policy. Typed incomplete, failed and
cancelled outcomes preserve stage context and original constituent causes.
Historical mapped intersection failures remain in the receipt as historical
evidence. Existing mapped validation and frozen replay stay selectable.

This is validation-only evidence. Publication still requires complete history,
certified requested/effective/achieved measures and final callback-free source
rebinding. RustyCADKernel#10 owns migration/deletion of mapped checker authority
for this admitted path after the full-operation corpus gate, within ADR0014's
application R3 limit. No workspace version or application acceptance changes.

### Opt-in checked GUI surface outcomes

`Graphic3dRenderDriver::with_gui_surface_policy` and
`with_backend_and_gui_surface_policy` select immutable `CheckedV2` GUI target
checking. Existing constructors retain `LegacyV1` replay. Use
`RenderError::gui_surface_outcome()` to distinguish surface-only refusal from an
actual fault accompanied by surface evidence. Inspect `primary_failure()` and
`observed_failure()` for compound details; native window/display getters retain
their typed causes. Never treat a compound renderer fault as resize recovery.

A fresh packet and successful redraw are required after an observed target
change. Old captures remain unavailable after away/back extent or explicit
same-handle rebind. No automatic retry or stale-image fallback is introduced.
The original primary is fixed; repeated real observations replace one latest
companion, while closure remains distinct. Unknown native extents refuse instead
of substituting requested dimensions. Ordinary model rendering is unchanged.

Migration/deletion task `GUI-SURFACE-LEGACY-DELETE` belongs to the Martensite Vulkan
maintainer and Oblikovati#3630 consumer, with a one-milestone limit after recorded
consumer adoption. Default changes/removal require a separate version decision.
This additive API targets the next compatible patch above; it is not application
acceptance or a publication. See [ADR0028](../adr/0028-typed-gui-surface-outcomes.md).

### Conditional polynomial extrusion-side integral

`certify_polynomial_side_integral` adds behavior v1 for full-[0,1] polynomial
Bézier/line side integrals under supplied affine embeddings. It returns a
certified scalar interval, absolute area-error bound, explicit policy and work,
or a typed incomplete/cancelled/input failure. Default absolute area error is
1e-5 with at most 4096 subdivisions; policies are never silently widened.
Existing signed boundary/sweep and mapped integration behavior is unchanged.
No call establishes face/body validity or replaces source-bound region checks.
See [ADR0024](../adr/0024-conditional-polynomial-extrusion-side-integral.md).

### Native window lifecycle

Native-window-lifecycle behavior v1 retires an X11 window after its matching
`DestroyNotify` is delivered. Applications should continue delivering native
events to `XwWindow::process_message` before issuing subsequent view operations.
Closed targets expose their original native ID and destruction cause; renderer
operations return typed closed-target failures and refuse cached images. Rebind
to a live window and submit a fresh GUI packet before capturing a new frame.

Explicit rebind always invalidates cached frames and GUI packets, including a
rebind with the same native handle and extent. Submit a fresh packet and redraw
before capture; numeric XID equality cannot establish a shared lifetime. Ordinary
live-rendering output is unchanged. Prior fatal behavior is retained through
revision-bound diagnostic replay; see the [migration decision](../adr/0018-delivered-native-window-destruction.md).
Unreported native destruction, externally initiated display reset, the original
intermittent `BadWindow` and fresh performance acceptance remain open.

### Retained native display connections

Native-display-lifecycle v1 refuses `AspectDisplayConnection::init_checked` while
owned/wrapped XwWindow objects or Vulkan instances retain native consumer leases.
The old connection remains unchanged. Drop the retaining windows and Vulkan
runtime before resetting, or create a separate connection. A removed view alone
does not end Vulkan's connection retention.

Use `init_checked` for typed operation/identity/cause/count diagnostics. Existing
`init` remains a lossy legacy error adapter for one migration milestone only;
[ADR0019](../adr/0019-retained-native-display-connections.md) records its deletion
task and deadline. This does not certify externally owned or independently
aliased raw display lifetimes. Existing self-alias and failed-unleased-reset
hazards, historical intermittent BadWindow, performance and application
acceptance remain open. Versioning and publication remain with the coordinator.

XwWindow native operations and renderer admission use the original leased display,
even when protected display metadata is replaced. Custom AspectWindow implementations
retain the default metadata lookup and must define their own native binding lifetime.
The explicit non-null invalidate_content display override is preserved and leased
through its send callback; same-server XID validity and external raw lifetime remain
caller obligations. Failed admission causes no send and cannot be reported by that
legacy unit-return adapter; it is not a successful invalidation or delivery guarantee.

### Opt-in unlit side colors

`Graphic3dRenderDriver::with_unlit_face_color_policy` and
`with_backend_and_unlit_face_color_policy` accept
`RenderUnlitFaceColorPolicy::SideColorsV2` for distinguished, untextured unlit
triangle RGBA and front-only vertex colors. Existing constructors remain on
`LegacyV1` and preserve the owned rejection contract. Callers opting in should
record `behavior_version() == 2` with replay settings. Back alpha participates in
BlendAuto routing and the existing strict Mask/MaskBlend cutoff. Without a
vertex color array, the front-only flag has no effect; distinction chooses the
back interior RGBA. Textured and fixed-function behavior is unchanged.

Default migration and V1 deletion remain gated by
[ADR 0021](../adr/0021-unlit-side-colors.md); this entry does not change workspace
versions, activate the default, or complete a release/milestone.

### Opt-in cumulative pcurve import

BRepGraph import can select `populate::PCurveImportBehavior::CumulativeOccurrenceV2`
through the additive `*_with_behavior` population entrypoints or
`ShapesViewMut::add_with_options_and_behavior`. This preserves stored pcurves
on located face/wire/edge occurrences, including both directed seam uses.
Existing entrypoints and `Options` layouts keep their V1 behavior.

Selection applies to new definitions only: append reuses existing definitions
without repair. Migrate by rebuilding a fresh graph with V2 and auditing it;
a successful import is not body validation. Polygon/triangulation lookup and
mutable graph ownership are unchanged. Default migration and V1 production
removal remain gated by [ADR0026](../adr/0026-cumulative-pcurve-import.md).

### Private frozen topology evidence

ADR0033 adds exact combinatorial topology evidence for RustyCADKernel#10's named
analytic prism. The existing private `freeze_prism` retains containment V1 and
its bytes. Publication composition must explicitly select
`PrismFreezeBehavior::OrderedTraversalV2`, then certify that exact immutable
projection; V1 has no retained wire traversal and is incomplete for this check.
Closure, paired directed uses, endpoint-germ links, connectivity and Euler2 do
not establish geometric outwardness, embedding or valid-solid status. The #10
publication coordinator owns the same-C1-milestone migration of its publication
path to V2; diagnostic V1 replay remains selectable until the recorded gate.

### Private sealed publication diagnostic projection

- ADR0048 adds a private owned refusal adapter fed only by an actual resolver
  invocation packet. It preserves caller request/revision/policy bits, the actual
  naming plan, original outer classification, explicit child-class provenance,
  callback/native fields and a versioned typed replay.
- Unsupported payload families and unqualified entity contexts remain explicitly
  projection-incomplete with the same original local failure retained. This is
  intermediate Kernel#10 work, not acceptance of a complete public one-call
  failure API. The existing operation-contract owner and ADR0014 application R3
  migration/deletion obligation remain; no workspace version changes here.

### Private owned projection-refusal evidence (ADR0056)

The single-boundary scoped operation can move its actual post-publication
projection refusal into an immutable owned diagnostic. Exact caller input,
accepted child publication context, original typed cause and outer callback are
retained with explicit class provenance. Earlier producer behavior and replay
remain unchanged. Other scoped refusal families still block a public complete
owned-result contract; RustyCADKernel#10 owns that migration and deletion gate.
