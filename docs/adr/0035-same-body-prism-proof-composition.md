# Same-body prism proof composition, private behavior version 1

## Decision

Join the current polynomial embedding certificate to an immutable prism projection
through the existing actual-context and caller-authored identity machinery. This
is an explicit private operation, not an application workflow requiring callers
to sequence private inspectors. A later ordered operation will consume this join
internally. The join itself leaves body completion and every current validation
stage incomplete.

Pin the selectable frozen containment V1 replay before structural seam sharing.
The owned 89,921-byte fixture is `frozen/fixtures/containment-v1.bin`. Reuse the
existing capture/bind_projection, chart capture/proof, encoding and final recapture
path. Ordered publication composition selects the separately reviewed
OrderedTraversalV2 path; no second graph population, wire explorer, geometry
validator or replacement intersection engine is introduced.

## Exact identity and operand join

The fresh embedding inspector supplies CurrentPrismBinding and its determinant,
regularity, actual source/copy/closure operands, three trimmed domains and six
self/pair conclusions. Match each actual chart output to its unique bound face
context, then each actual trim use within that face ancestry. Retain the existing
FrozenPrismKey/FrozenUseKey and source/original-parent names. Raw addresses and
returned traversal/root ranks are temporary lookup evidence only.

A caller supplies an AuthoredClosureContact semantic ID before lookup, paired
with the actual report contact and original boundary identity. Its ID is nonzero
and distinct from the operation's existing authored IDs. Both actual fields must
match the fresh source-bound closure relation. Persistent replay contains that
semantic ID, never report/candidate-root indices. Candidate closure stages are
normalized to selected/complementary by actual face identity; candidate-list
position does not become persistent identity.

Compare every actual chart operand with the frozen counterpart using the existing
exact encoders: coefficient bits, stored weights, ranges, placements, surfaces,
pcurves, expectations, height and extrusion. Geometric encoding does not encode
identity; therefore context/source/parent matching is a separate required check.
Retain source/copy snapshots and every closure context with its semantic stage,
authored original, orientation, placement, point, limits, root options and proof.
Retain regularity coefficients/options/complete isolation and all six named
trimmed-domain conclusions. Preserve complete parent multiplicities before the
existing frozen history's set projection, including each disposition separately.

The joined replay includes the complete immutable projection and complete named
proof operands/conclusions/options/limits. It is not a digest, cardinality summary
or address-containing Debug dump. Canonical sorting orders already-named records
and preserves duplicates; it never assigns identity from returned rank or point
coordinates. Independent processes must compare the entire replay byte for byte.

## Raw local vertex operands

BRepTool::pnt applies a binary64 placement and can round. The join additionally
owns one JoinedVertexOperand per authored directed vertex use: physical vertex
key, directed use key, raw local point from the existing safe
`brep::access::vertex_tshape(...).pnt()` accessor and the actual owner placement.
The existing rounded world point remains separately available in the unchanged
frozen view. The join proves capture/binding consistency, not invertibility of
that frame or exact local-to-world transport. ADR0036 consumes these operands
with the existing exact residual and determinant tools.

For example local x=1 and translation 2^53 produce a rounded world point 2^53,
while exact transport is 2^53+1. Equality against the rounded observation cannot
establish a zero exact residual. Keep this distinction and refuse missing/stale
raw capture. Do not choose one directed placement by traversal order when a
physical vertex has multiple uses; retain every use for explicit equivalence
proof by the metric policy.

## Publication boundary and failures

After the last external callback, use the existing callback-free current-binding
rebind, full frozen recapture with the same behavior, and a fresh exact join/raw
operand replay comparison. No callback follows that final proof. Missing,
unsupported, stale, failed and cancelled work retain typed causes and operation/
entity context; none returns a partial joined success. Owned output reads are
lock-free and contain no mutable Shape owner or compatibility cache.

This join does not authorize topology, outward orientation, metric tolerance,
complete deletion/history composition or body success. In particular the nominal
historical AlertIntersectionFailed and historical StageCoverage remain retained.
A future explicitly versioned ordered validator must name the authoritative
current topology → geometry/orientation → independent embedding self-incidence →
tolerance checks on this same body, and reject unresolved required current
findings. Replacing mapped SI acceptance needs an explicit migration/deletion task
and corpus gate; historical attempted-checker evidence is never silently erased
or promoted. V1 diagnostic replay remains selectable until that migration.

## Acceptance

Preserve frozen V1 bytes through structural extraction. Test exact source/use/
contact links, complete parent multiplicities, altered coefficients/ranges/
placements/E, missing or extra roles, wrong authored keys, raw-point mutation,
final callback mutation, cancellation and input isolation. Compare complete
non-address joined bytes serially, across threads and in two processes. Retain
current compiler/source/input hashes and explicit test scope. Ordinary Send/Sync
and replay checks do not close the previously recorded host TSan startup gap.

This bounded prerequisite does not complete Kernel #10 or broaden the current
single-Jordan polynomial admission contract.

### Original closure operands

The join also owns each of the twelve actual directed closure contexts across
original, census, partition, selected/complement candidate, and copied stages.
A shared enumeration preserves the legacy stage failure order. Actual context
identity establishes a bijection with retained closure evidence before semantic
stage/contact names enter replay; missing or duplicate contexts refuse the join.
The raw local point and owner placement are captured independently of the
historical rounded world coordinate. Final callback-free replay recaptures both.

The metric target remains the original captured source query from the existing
singleton-input and exact-source-query path. The join owns original and copied
coefficients, construction coefficients, support and occurrence placements,
native/basis intervals, both parameter maps, exact singleton bounds, root options,
and the requested world limit. No candidate-curve substitution is inferred.
ADR0036 must evaluate exact raw transport against these immutable operands before
claiming closure tolerance consistency. This join alone makes no such claim.

### Callback and replay boundary

`compose_prism_proof` performs minimal cardinality admission and captures raw
source/body vertex probes before the first callback. It then uses the existing
fresh embedding entry and selectable ordered frozen capture. After its final
callback, `rebind_joined_prism_proof` repeats the shared current binding, the
existing full V2 recapture, and the complete authored join/raw-query encoding.
The initial raw probes are compared once more without callbacks. Malformed
source/census/candidate counts return typed refusal before indexed legacy paths.
Downstream consumers reuse the callback-free rebind after their own callbacks.

Parameter maps have explicit variant tags and endpoint binary64 bits; root
policies encode versions, degree/bisection budgets and width bits. The encoding
retains signed zero and NaN payload distinctions without admitting invalid
numerical inputs. Historical V1 bytes are unchanged. The owned query's
`source_query()` borrows the existing assembler, preserving the original curve,
construction support, maps, interval and root policy.
