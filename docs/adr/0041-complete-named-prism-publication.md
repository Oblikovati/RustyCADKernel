# ADR0041: complete named prism publication

Status: proposed; private implementation pending complete acceptance.

## Decision and supported operation

Introduce private publication behavior V1 over the existing source-bound,
single-Jordan polynomial prism operation. The first complete operation takes the
actual retained contact transaction, original borrowed sources, retained prism
receipt and explicit authored bindings. It hides proof sequencing and returns
completion, current authoritative coverage, historical diagnostics, complete
history, requested/effective limits and achieved error together. Broader public
source admission and generalized profiles follow this complete operation gate.

One `JoinedPrismProof` supplies the immutable body and all actual operands. Ordered
validation, complete history and joined measures must each bind its complete
bytes. A missing, failed, stale, cancelled or inconclusive required result cannot
produce successful publication. The final callback precedes both callback-free
shared join rebind and complete-history rebind; no user callback occurs after
those checks. The history check includes rejected/intermediate contexts and
exhaustive query outcomes beyond the join's final body operands.

Caller-assigned operation, region, original member, directed use and closure
contact names exist before lookup. Actual context identities are temporary
lookup evidence. Returned order, root rank, coordinates, proximity and addresses
never assign persistent names. The existing history owner supplies the single
history census/binding interface. Publication adds no second graph, geometry,
contact or history engine.

## Result ownership and diagnostics

Only owned immutable values enter the result; no mutable `Shape`, live receipt,
borrowed bridge or operation-local identity escapes. The result owns one joined
projection and the certificates bound to it. Read views take no lock. All public
result candidates must satisfy compile-time Send/Sync and isolation/replay gates.

Existing private join refusals can retain typed legacy diagnostics, including
mutable operation-local shapes. The initial private non-success outcomes retain
those original causes; they are not published bodies or a public Send/Sync
outcome contract. Public refusal publication requires a separate owned typed
diagnostic projection. Accepted results never retain those failure payloads.

The measurement read view explicitly names the signed sweep integral. Negative
extrusion may produce a negative signed report. This seam neither calls it a
nonnegative physical volume nor recomputes it from a rounded representative.

Historical mapped attempted checks, including self-intersection failures, remain
recorded with their original class and status. Current acceptance comes only
from the explicit ordered proof mode. Standalone frozen projection
`is_valid_body()` and legacy receipt coverage remain unchanged. Publication may
supersede historical acceptance for this admitted operation only through the
versioned authoritative check decision; unresolved current required findings
always prevent success.

## Owned baseline and independent acceptance

`publication/fixtures/join-v1.bin` is the exact 193,080-byte artifact from source
93fac56f229fc299080f38581bdf3d5a82acbcfd, retained in the structural evidence receipt.
Its SHA-256 is
`de1f88a80716a820eddc03254425f0400b5743e425126e3d43bf843ae2908871`.
The baseline test also pins legacy incomplete completion, unknown achieved error
and incomplete frozen coverage. No previous baseline is replaced.

Acceptance must exercise one actual named operation with independently checked
geometry/area/volume, all stages bound to identical complete bytes, typed refusal
at every missing/changed gate, cancellation/reuse, source and history edits at the
final callback, input/result isolation, and serial/thread/two-process exact full
result replay. Ordinary concurrency tests do not complete the retained host
ThreadSanitizer requirement. Public release acceptance remains separate.

## Migration

This initial seam is crate-private and additive. Existing diagnostic and mapped
interfaces remain selectable and byte-identical. Promoting a public interface
requires explicit supported-domain documentation and semantic version/changelog
review. This private implementation alone does not complete Kernel #10's broader
public/general-profile release contract.

## Private implementation checkpoint

`publish_named_prism` accepts a `PrismPublicationRequest` with explicit source,
copy and intermediate history bindings and versioned policies. Its owned
`PublishedNamedPrism` combines the single joined body, ordered certificate,
complete history and certified measurements. `signed_sweep_integral()` retains
the signed report under negative extrusion and reversed traversal. The full
replay length-delimits all four child receipts, including their policies,
authored names, operand bits and conclusions.

The history stage calls the existing conditional projection helper. The sole
terminal callback then precedes shared join rebind and history-only reprojection.
An exhaustive partition member query can change while the shared join still
binds: an owned regression changes its deletion answer to a typed native failure
and requires the additional history reproject to refuse. Partition tree removal
and rejected-parent multiplicity are already rejected by the shared join; the
new tests retain that earlier rejection rather than assuming a later failure.

Initial private refusal values remain operation-local, preserve typed child
causes and may borrow input diagnostics. Accepted results are owned and have no
input lifetime. A separate owned-refusal projection is required before a public
outcome contract. This checkpoint is not full release acceptance.
