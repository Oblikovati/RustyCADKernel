# Shared Martensite exact construction arithmetic

This structural prerequisite moves the proved line world-construction helper to
`roots/certificate_arithmetic/world.rs`. The original line adapter delegates to
the same coefficient expressions with owned controls/weights arguments. The
machine-checked equivalence receipt compares the unchanged constructor and all
remaining expressions after private visibility/import/formatter changes.

The raw convolution helper preserves dense coefficient magnitude, trailing zero
coefficients, and left-major/right-minor cancellation polling. Empty operands
produce empty output without a poll. Content normalization remains outside it.
The private module temporarily permits unused production symbols until the
independently owned metric consumer integrates this checked prerequisite.

(40 passed, including existing world regressions and two convolution tests);
`cargo clippy -p rustycad-tkmath --all-targets --all-features -- -D warnings`
(exit 0); `cargo fmt --all`. Compact debug-free profiles, incremental disabled,
