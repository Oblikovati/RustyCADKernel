# Martensite native text Blend/XOR audit

OCCT's `Aspect_TODT_BLEND` uses a **bitwise color logic operation**, rather than an alpha blend approximation. At pinned `OpenGl_Text.cxx` lines 805–811, desktop OpenGL enables `GL_COLOR_LOGIC_OP` and selects `GL_XOR`; the ordinary foreground glyph pass follows. The existing font fragment shader still discards when color alpha times glyph coverage is at most 0.285. Text rendering resets the logic operation afterward. The OpenGLES path does not enable this desktop logic operation.

The local native probe observes `logic_enable = 1`, `logic_op = 5382` (`GL_XOR`) and `GL_BLEND = 1` during the real glyph draw. White glyphs over blue produce 102 solid yellow pixels. Changing foreground alpha to 0.4 yields 56 yellow pixels because of the font cutoff, rather than translucent yellow blending. Actual color/depth buffers, trace rows and PNGs are retained in `porting/runtime-evidence/decal-text-2026-10-12/native-blend-*`. Native `buffersOpaqueAlpha` keeps alpha writes disabled; the current Martensite attachment write mask already preserves that behavior.

Both host and lavapipe expose `logicOp`. The subsequent [Martensite Blend/XOR implementation](vulkan-blend-text.md) enables this optional feature, rejects unsupported requests explicitly and uses a UNORM attachment view for real logic operations. Ordinary draws continue through the compatible sRGB view. Rendering boundaries retain color/depth/stencil with LOAD; alpha cutoff and RGB-only writes remain native.

The native colored probe now observes actual sRGB-enabled, unsigned-normalized RGBA8 attachment state and the RGB-only write mask. Thirty-nine retained variants and thirty-three real Set2D variants have repeated raw native buffers and both-device captures. The dense 256-color oracle preserves one-byte quantization failures; ordinary Vulkan sRGB glyph conversion matches every native sample on AMD, isolating a future hardware-conversion seam. The wider legacy text family remains partial, and no whole `OpenGl_Text` API credit is added.

The original Decal audit and its raw captures remain historical evidence. Implementation details, reproduction commands and exact limitations are recorded in the Blend document and `porting/runtime-evidence/blend-text-2026-10-12`.
